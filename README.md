# Eagle 素材导入助手（Chrome 扩展）

自动识别网页上的图片素材，并可直接选择 **Eagle** 文件夹导入。

- 打开插件弹窗，自动列出当前页面的所有图片（含 `<img>` 与 CSS 背景图），勾选后一键导入到指定文件夹。
- 鼠标悬停任意图片，会浮出工具条，可 **直接选择文件夹** 单张导入（用过的最近文件夹会被记住）。
- 右键图片 →「导入到 Eagle」子菜单，可直接挑选目标文件夹导入。

## 前置条件

1. 已安装并运行 **Eagle** 桌面端（本插件通过 Eagle 本地 API `http://localhost:41595` 通信）。
2. 使用 Chrome / Edge / 基于 Chromium 的浏览器。

## 安装（开发者模式加载）

1. 生成图标（首次需要）：
   ```bash
   cd eagle-importer
   python3 gen_icons.py
   ```
2. 打开浏览器扩展管理页：`chrome://extensions`
3. 右上角开启「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本 `eagle-importer` 文件夹。
5. 点击工具栏拼图图标，将「Eagle 素材导入助手」固定到工具栏。

## 使用

- **批量导入**：点击扩展图标 → 在弹窗里选好文件夹 → 勾选图片 →「导入到 Eagle」。
- **单张导入**：鼠标移到网页图片上，会浮出紧凑小工具条（优先浮在元素上方/下方，不遮挡内容，移开鼠标自动消失）→ 点「▾」展开文件夹，**点任意文件夹即立即保存**（点「（库根目录）」保存到根目录）；直接点「导入 Eagle」则保存到上次使用的文件夹。
- **悬停工具条开关**：弹窗内「悬停工具条」勾选框可关闭/开启悬停浮层。
- **右键导入**：在图片上右键 →「**导入到 Eagle**」→ 在子菜单里选「（库根目录）」或任意文件夹，即把这张图导入到所选文件夹（选过的文件夹会被记住，供悬停工具条与弹窗使用）。
- **快捷键**：`⌘⇧E` 打开弹窗；`⌘⇧K` 一键复制画板 PNG 并导入（画布类设计工具，见下）。

## 画布类设计工具（即时设计 / Figma 等）

这类工具的画板内容绘制在 `canvas` 里，DOM 上没有图片，只能借它自己的导出能力：

- **推荐：手动复制 + 快捷键导入**（多选/大画板都可靠）：先在设计工具里「右键 → 更多 → 复制/粘贴 → 复制 PNG 图片」，再按 `⌘⇧K`，扩展会直接读取剪贴板里的新图片导入 Eagle（不会右键、不会改动你的选择）。
- **一键自动（仅单选可靠）**：剪贴板没有新图片时，`⌘⇧K` 会退化为用 `chrome.debugger` 在画布上模拟真实右键，逐级点开「更多 → 复制/粘贴 → 复制 PNG 图片」再导入。
  - 执行期间页面顶部会出现「正在调试此浏览器」提示条，完成后自动消失。
  - 该页开着开发者工具时会互相占用，先关掉 DevTools。
  - 多选时对方工具会把「右键点到的对象」改成当前选择，可能导出错图，请用上面的推荐方式。
- **手动复制 + 自动导入**：右键 → 更多 → 复制/粘贴 → 复制 PNG 图片，然后按 `⌘⇧E` 打开弹窗，会自动读取剪贴板并导入；读不到时弹窗会显示粘贴区，按一次 `⌘V` 即可。

> 弹窗打开时会自动按需注入内容脚本，无需手动刷新。若仍提示「无法读取页面图片」，通常是因为当前是不支持的页面（浏览器新标签页、扩展管理页、应用商店页等）或本地 `file://` 页面未开启文件访问权限，请换到普通网页使用。

> 缩略图优先在**页面上下文**抓取（自动携带正确 `Referer`，可破解 `img.js.design` 这类防盗链），失败后再由后台 Service Worker 用 `declarativeNetRequest` 补 `Referer` 兜底，可绕过混合内容、跨域、需要 cookie 等情况；`blob:` 图片由内容脚本转换。若个别图片仍无法预览，会显示「✕」，但不影响导入。
>
> 防盗链站点建议在重载扩展后**刷新页面一次**，以确保页面上下文抓图可用（未刷新时仍会走后台 DNR 兜底）。

## 工作原理

- `background.js`：Service Worker，封装 Eagle 本地 API（`/api/folder/list`、`/api/item/addFromPath`、`/api/item/addFromURL`），注册右键菜单；用 `declarativeNetRequest` 会话规则给后台抓图补 `Referer`，把 http(s) 图片抓成全分辨率数据后再**落盘成临时文件**交给 Eagle 的 `addFromPath` 导入（Eagle 4.0.0 直接接收 base64 会在原生层崩溃退出），导入完成后自动删除临时文件。
- `content.js`：注入页面，扫描图片素材、在悬停时注入带文件夹选择器的工具条（Shadow DOM 隔离样式）；在页面上下文抓取图片（Referer 正确），并把 `blob:` 图片转成 dataURL。
- `popup.*`：弹窗 UI，负责扫描、选择、批量导入（显示缩略图）。

## 说明

- Eagle 官方扩展为闭源商店版，仅支持拖拽到「最近文件夹」；本扩展支持**在图片上直接选择任意目标文件夹**，并开源可自定义。
- 所有通信仅在本机 `localhost` 与 Eagle 之间发生，不上传任何数据。

## 目录结构

```
eagle-importer/
├── manifest.json     # 扩展清单（MV3）
├── background.js     # Service Worker：Eagle API 封装、右键菜单、后台抓图
├── content.js        # 内容脚本：图片扫描、悬停工具条
├── popup.html/js/css # 弹窗 UI：扫描、选择、批量导入
├── gen_icons.py      # 生成 icons/ 下的图标
├── icons/            # 扩展图标
└── LICENSE           # MIT
```
